# Asset Packs for Red Frontier

These are the best practical sources for building a clean, stylized browser game quickly.

## Best free / low-cost options

### 1. Kenney.nl
Best overall for this project.

Why use it:
- clean, readable 2D shapes
- strong sci-fi and industrial style
- UI, props, vehicles, and world elements
- great for fast browser prototyping

Use for:
- rovers
- conveyor pieces
- mining tools
- crates and objects
- UI icons
- terrain props

### 2. OpenGameArt.org
Great for free art and scenic props.

Why use it:
- many sci-fi, industrial, and space-themed art packs
- often free and available for games
- good for terrain detail and environment props

### 3. Itch.io pack market
Good for inexpensive targeted asset packs.

Look for:
- top-down sci-fi
- robot packs
- industrial structures
- UI packs
- space base packs

### 4. Synty / low-poly asset packs
Good if you want a more stylized 3D-like world without full realism.

Useful for:
- buildings
- terrain chunks
- props
- sci-fi objects

### 5. Phaser and procedural graphics
Useful for custom UI, tiles, and effects.

Use to create:
- panel backgrounds
- status bars
- progress rings
- hover highlights
- dust, sparks, glows

## Recommended combination for this project

- Kenney.nl for the base 2D industrial/sci-fi visual language
- custom Mars terrain and UI panels in your own palette
- custom rover silhouettes and habitat modules
- Phaser procedural effects for energy, dust, and selection feedback

## Specific pack suggestions

Search these terms:
- top down sci-fi tiles
- industrial robot sprite pack
- space base asset pack
- sci-fi UI kit
- mining resource sprites
- top-down building pack
- Mars terrain tiles

## Practical strategy

For a 4-week deadline:
- use 1-2 strong packs as the base
- do not chase custom art for every item
- build one consistent visual theme across all sprites and panels
- use your own palette and custom UI to make the project feel custom

## Final recommendation

Start with Kenney.nl, then add selective custom props and UI. That gives the best balance between speed, quality, and readable style.
