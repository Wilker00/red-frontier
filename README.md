# Red Frontier

A cooperative browser game where players write code to operate rovers, gather resources, and build a first habitat on Mars.

## Project status

This repository now includes:
- a visual design guide for the game
- a curated list of asset packs to speed up production
- a starter browser app for the Red Frontier UI shell and mock mission layout

## Structure

- `apps/web` — React + TypeScript starter browser app
- `docs/art-style-guide.md` — exact art direction and color system
- `docs/asset-packs.md` — free and cheap asset sources

## Quick start

```bash
cd apps/web
npm install
npm run dev
```

## Game vision

Red Frontier is a multiplayer space-exploration coding game in which players collaborate to build a Mars settlement. The first release focuses on a two-player cooperative mission with shared resources and code-driven automation.
